# Systematic chest radiograph review

Source-grounded background: Eze's Table 1.2 organizes review around technical factors,
airway position, the cardiac/mediastinal contours, diaphragms and pleural recesses,
lung fields and hila, and the bones and soft tissues. It also calls attention to
regions obscured by overlapping structures, including the apices and retrocardiac
region. A structured review helps direct attention; it does not establish a finding.

Project application: use this checklist to choose focused image questions relevant to
the current task within the existing tool-call budget. Match each candidate claim to
the relevant structure and side. Keep the image observation separate from the verdict
about the report. If a structure is poorly shown or an observation is equivocal, retain
that uncertainty instead of filling in a normal finding from the checklist.

This chapter is general reference material. It contains no patient examples, expected
answers, attack locations, or private strategy notes. It is not a validated detection
algorithm or a guarantee that a VLM can inspect every listed structure reliably.

Source: Kenneth C. Eze. *Radiology for Medical Students*. Mindex Publishing Co. Ltd.,
2012. Table 1.2, printed p. 5; local PDF viewer p. 19.
