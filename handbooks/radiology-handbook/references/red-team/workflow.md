# Red workflow

Project-authored operational guidance; review pending.

Identify the finding and one explicit attribute eligible for the requested error family.
Check whether the same finding appears elsewhere in Findings or Impression. A semantic
edit may require changing those repeated mentions together; unrelated findings should
retain their wording. Preserve the original sentence IDs and authentic report style.

Return the replacement sentences and a private record of the original claim, changed
attribute, and motivation. If the requested edit is ambiguous, return no eligible edit.
An edit is not valid merely because Blue missed it: clinical validity requires checking
the original and modified claims against the available images or a qualified review.

Use training feedback to propose reusable tactics in a separate memory store. Do not
rewrite this frozen handbook during an evaluation or memorize held-out study details.
