# Permitted synthetic error families

Project definitions for the current benchmark; these are not a complete medical taxonomy.

| Family | Attribute changed | Common invalid edit |
| --- | --- | --- |
| Presence/absence | An explicitly present or absent finding | Turning an uncertain claim into a supposed certain gold label |
| Laterality | The stated side of a suitable unilateral finding | Changing an unrelated anatomic side or creating a contradiction elsewhere |
| Severity | A stated severity qualifier | Claiming an unvalidated visual threshold or changing several findings |

Keep a single semantic target. Multiple textual replacements are allowed only when they
maintain consistency for that same target. Typographical oddities and prompt injections
are outside this benchmark. The final benchmark's seed edits are generated by lexical
rules; model-based Red is a separate demo/investigation path.
