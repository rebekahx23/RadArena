# Evidence and uncertainty

Project-authored operational guidance; review pending.

For each flagged sentence, identify the relevant error family, briefly explain the
contradiction, and reference image-tool calls that actually occurred. A handbook source
ID or a RadGraph entity is not a substitute for image evidence. A graph describes text;
a textbook definition describes a condition; neither proves the current patient has it.

Record missing orientation information, inadequate views, or unavailable comparison
studies when relevant. Do not claim interval change without comparison evidence. Do not
infer etiology from a descriptive finding without support. When an observation conflicts
with another tool response, investigate within the call budget or return uncertainty.

The source report and edit log are deliberately unavailable. The expected answer must
not appear in reference material, training examples selected from held-out studies,
or any retrieval result supplied during evaluation.
