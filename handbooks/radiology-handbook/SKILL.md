# RadArena radiology handbook

Open the index for your assigned role, then select only chapters relevant to the
current question. The application supplies the available chapter catalog and enforces
access. Do not read the entire library linearly.

- Red: [Red role index](references/red-team/SKILL.md).
- Blue/verifier: [Blue role index](references/blue-team/SKILL.md).
- Shared books: [reporting](references/reporting/SKILL.md),
  [medical library](references/medical-library/SKILL.md),
  [tool reference](references/tools/SKILL.md).
- [Source provenance and review status](SOURCES.md).

This project-authored draft requires qualified radiologist review. The library has no
patient cases, gold edits, test answers, or learned memories. It is read-only through
the application interface; writable training memory is separate. Some books may be
unavailable in an ablation condition. Use the catalog actually supplied for this run.
